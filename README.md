# Planilla CNEL EP en Python

Este proyecto simula la generación de una planilla de consumo eléctrico de la empresa CNEL EP.

## 🚀 Cómo usar
1. Instalar Python 3 en tu computadora.
2. Descargar el archivo `planilla_cnel.py`.
3. Ejecutar en consola: python planilla_cnel.py
4. Ingresar los datos solicitados (nombre, suministro, consumo en kWh).
